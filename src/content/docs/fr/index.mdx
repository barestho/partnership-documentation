## Introduction
L'API Barestho vous permet d'intégrer la gestion de réservations de table directement 
dans vos propres applications et services. 
Elle expose un ensemble d'endpoints REST retournant des réponses au format JSON.

Cette documentation s'adresse aux développeurs partenaires souhaitant interagir programmatiquement 
avec la plateforme Barestho : consultation des disponibilités et création et gestion de réservations.

Si vous souhaitez rapidement mettre en place votre intégration, 
nous vous invitons à commencer par le guide "[communication avec l'API](/guides/01-api-communication)".
