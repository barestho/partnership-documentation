## Gestion des webhooks

Les webhooks se gèrent via l'endpoint suivant, en utilisant vos identifiants partenaire :

```
https://public.api.barestho.com/api/v1/partnership/webhooks/
```

Consultez la référence API pour la liste complète des opérations disponibles (création, consultation, suppression).

## Sécurisation

<Aside type='caution'>
La vérification de la signature est facultative mais fortement recommandée. 
Ne pas l'implémenter expose votre système à des requêtes frauduleuses.
</Aside>

Chaque requête émise vers votre webhook est signée par Barestho à l'aide 
d'un [**HMAC-SHA256**](https://fr.wikipedia.org/wiki/HMAC) calculé à partir de votre `auth_token`, 
de la charge utile de la requête ainsi que de l'heure actuelle sous la forme d'un *timestamp*. 
L'`auth_token` est défini par le partenaire lors de la création du webhook.

Les en-têtes suivants accompagnent chaque requête :

| En-tête | Contenu |
|---|---|
| `X-Webhook-Signature` | Signature HMAC-SHA256 |
| `X-Webhook-Timestamp` | Horodatage de la requête (Unix) |

### Vérification de la signature

Vérification de la signature
Pour valider qu'une requête provient bien de Barestho, reconstituez la signature comme suit :

1. Récupérez l'horodatage depuis `X-Webhook-Timestamp`
2. Sérialisez le corps de la requête en JSON sans espaces, avec les clés triées alphabétiquement
3. Construisez le message à signer : `{timestamp}.{json_sérialisé}`
4. Calculez un HMAC-SHA256 de ce message en utilisant votre `auth_token` comme clé
5. Préfixez le résultat de `sha256=` et comparez-le à `X-Webhook-Signature`

import hmac
import hashlib
import json
import time

SIGNATURE_PREFIX = "sha256="
TIMESTAMP_TOLERANCE_SECONDS = 300

def sign_payload(secret: str, payload: dict, timestamp: int):
    """
    Sign a webhook payload using HMAC-SHA256.

    :param secret: The shared secret key
    :param payload: The payload as a dict
    :param timestamp: The Unix timestamp of the request
    :return: The hex signature prefixed with 'sha256='
    """

    dumped_payload = json.dumps(
        payload, 
        separators=(',', ':'), 
        sort_keys=True,
    )

    message = f"{timestamp}.{dumped_payload}"
    signature = hmac.new(
        secret.encode(),
        message.encode(),
        hashlib.sha256
    ).hexdigest()

    return f"{SIGNATURE_PREFIX}{signature}"

def verify_signature(secret: str, payload: dict, signature_header, timestamp_header):
    """
    Verify a webhook signature and reject stale requests.

    :param secret: The shared secret key
    :param payload: The raw payload as a dict
    :param signature_header: The value of X-Webhook-Signature
    :param timestamp_header: The value of X-Webhook-Timestamp
    :raises ValueError: If the timestamp is stale or the signature is invalid
    """
    request_time = int(timestamp_header)
    if abs(time.time() - request_time) > TIMESTAMP_TOLERANCE_SECONDS:
        raise ValueError("Request timestamp is too old")

    expected = sign_payload(secret, payload, timestamp_header)

    if not hmac.compare_digest(expected, signature_header):
        raise ValueError("Invalid signature")
