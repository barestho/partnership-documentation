## Troubleshooting & Support

If you encounter any issues with the Barestho Partnership API or need technical assistance, we are here to help.

### Technical Issues and Bug Reports

We use [**GitHub Issues**](https://github.com/barestho/partnership-documentation/issues) to track bugs, technical problems, and feature requests. This allows our development team to investigate efficiently and keeps the community informed of known issues.

Before opening a new issue, please search the existing ones to see if your problem has already been reported.

<Aside type="tip">
**Ready to report an issue?** Go to our GitHub repository: [**Barestho Partnership documentation Issues**](https://github.com/barestho/partnership-documentation/issues)
</Aside>

### How to file a good issue

To help us resolve your problem as quickly as possible, please include:
* **A clear description** of the problem.
* **The specific endpoint** you were calling.
* **The payload** (request body) sent (masking any sensitive API tokens).
* **The error response** received from the API (status code and JSON body).
* **Steps to reproduce** the behavior.

---

### Other Inquiries

For non-technical questions, partnership requests, or access authorization issues, please contact our support team directly via our official website or your account manager.

<Aside type="note">
For security-related issues (e.g., potential vulnerabilities), please do not open a public issue. Contact us privately at contact@barestho.com.
</Aside>
