## Introduction
The Barestho Partnership API allows you to integrate table reservation management directly 
into your own applications and services. 
It provides a set of REST endpoints returning responses in JSON format.

This documentation is intended for partner developers who want to interact programmatically 
with the Barestho platform: checking availability, as well as creating and managing reservations.

If you want to quickly set up your integration, 
we recommend starting with the guide "[communicating with the API](/guides/01-api-communication)".
